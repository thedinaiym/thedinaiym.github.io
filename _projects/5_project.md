A decentralized application enabling fractional ownership of real property via on-chain tokenization, built at ETH Bishkek 2025.

**Stack:** Solidity · Scaffold-ETH 2 · Status Network Sepolia · Python (scraper) · lalafo.kg

**Key features:**

- Smart contracts for fractional NFT ownership and ETH-based marketplace transactions
- Real property data parsed live from lalafo.kg and anchored on-chain
- Full end-to-end DApp: wallet connect, browse listings, buy fractions, trade on marketplace
