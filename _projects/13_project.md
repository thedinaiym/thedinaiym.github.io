A progressive web app startup helping students find housing and compatible roommates through deterministic lifestyle matching.

**Stack:** Next.js 15 · Tailwind CSS v4 · Supabase (PostGIS) · MapLibre GL JS

**Key features:**

- Deterministic roommate lifestyle-matching engine (not black-box ML) for transparent, explainable matches
- Geospatial housing search powered by Supabase PostGIS and MapLibre GL JS
- Zero-cost serverless infrastructure; built with Claude Agent–assisted development workflows

**Links:** [GitHub](https://github.com/thedinaiym/CampusNest)
